# BTC/USDT Bybit Bot — Android / Termux

**Безопасный старт:** проект по умолчанию работает в paper-режиме (симуляция) и не отправляет ордера. Реальная торговля фьючерсами с плечом не включена в этот шаблон. Сначала тестируйте на исторических данных и демосчёте Bybit. Торговля криптодеривативами может привести к полной потере депозита; при возрасте до 18 лет не подключайте реальный торговый аккаунт без родителя/опекуна и соблюдения правил платформы/страны.

## Что внутри
- BTCUSDT, свечи Bybit V5, таймфреймы 15m и 1h.
- EMA 50/200 как фильтр тренда, RSI и ATR для сигналов/стоп-уровней.
- Расчёт позиции от риска в USDT, с учётом примерной комиссии и минимального размера.
- В основном боте нет управления открытыми позициями и автоматического лимита дневного убытка; некоторые ограничения реализованы только в историческом тестере backtest_full.py.
- Сигналы и расчёты для симуляции; реальные ордера не отправляются. Незакрытые свечи исключаются.
- Никакого мартингейла, усреднения убыточной позиции или вывода средств.

## Установка на Android
1. Установите Termux из официального источника проекта F-Droid/GitHub.
2. Откройте Termux и выполните:
   ```sh
   pkg update && pkg upgrade
   pkg install python git
   ```
3. Распакуйте архив в папку телефона и перейдите в неё (`cd` в нужную папку).
4. Установите зависимости:
   ```sh
   pip install -r requirements.txt
   ```
5. Запустите проверку:
   ```sh
   python bot.py --once
   ```
6. Запустить цикл симуляции:
   ```sh
   python bot.py
   ```
7. Тест на истории:
   ```sh
   python backtest.py
   ```

## Настройки
Изменяйте `config.json`. Начальные значения рассчитаны на небольшой виртуальный баланс €29, переведённый условно в USDT (значение нужно сверить вручную; курс не фиксирован). `risk_per_trade` по умолчанию 0.01, то есть 1% виртуального баланса. `fee_rate` — только оценка комиссии; проверьте фактический тариф аккаунта. Фандинг и проскальзывание в реальном рынке могут ухудшить результат.

## API и безопасность
- Для получения публичных свечей API-ключ не нужен.
- Не храните API-ключи в коде и не присылайте их в чат.
- В этом проекте нет отправки торговых ордеров. Не добавляйте live-торговлю без независимого аудита, тестирования и понимания риска.
- Для будущего подключения только к Bybit Demo используйте официальный API V5 и ключи демо-среды; не используйте ключи основного аккаунта.
